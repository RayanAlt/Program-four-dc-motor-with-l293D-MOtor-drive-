# Program-Four-Dc-Motor-With-l293D-MOtor-Driver-
This program controls a 4-wheel robot using motor driver pins (M1 to M4).

it runs a times sequence indisde setup():
first move forward for 30 second
two reverse for 60 second
and after that aleernate turning right and left (5 second each ) for 60 seconds total
 stop after 150 seconds
